# Changelog

## 1.0.0
- Public GitHub release.
- One full library index stores each song's Like flag.
- Likes / All is selected at **download time**, so changing it does not require another scan.
- Likes remains the default.
- WAV and MP3 download modes.
- Persistent scan/download recovery.
- Automatic multiple-download helper.
- Download history avoids duplicates.
- 429 backoff for large libraries.
