# Privacy Policy — Suno Mass Backup

**Last updated: 2026-08-15**

Suno Mass Backup has one purpose: helping a user create a local backup of audio from the user's own authenticated Suno account.

## Data handled locally

The extension may locally process:
- the existing Suno authentication session in the user's open Suno tab;
- song IDs, titles, audio URLs, creation dates, completion status, and the user's Like flag;
- local backup progress and download history.

## Data sharing

Suno Mass Backup does **not** transmit this information to the extension developer or to an analytics/advertising service. Network requests required for the feature are made to Suno and Suno-hosted/CDN endpoints in order to read the user's library and request/download audio.

## Storage

Library indexes, queue state, and download history are stored locally using Chrome's extension storage. Removing the extension may remove this local extension data.

## Selling data

Suno Mass Backup does not sell user data.

## Limited use

Use of information received by the extension is limited to providing the user-facing personal-backup functionality described above.

## Contact / support

Use the GitHub Issues section of this repository for support, bug reports, and privacy questions.
